# Negyedik házi feladat

## Mit készítettem a héten

A héten a projektötletem problématérképét és ötletelés tábláját készítettem el. Definiáltam a központi problémát, majd a "How Might We" kérdések segítségével megoldási irányokat találtam ki, amiket egy 2x2-s mátrixban priorizáltam.

### Megoldás összefoglalása

A feladat során először tisztáztam a projektbriefet, az érintetteket és a fő user story-t. A problémaállításban megfogalmaztam, hogy a diákok számára gondot okoz a valós idejű információ hiánya a pályák telítettségéről, ami miatt gyakran feleslegesen utaznak oda. 

Az ötletelési fázisban több megoldást is kidolgoztam, amelyeket egy Hatás-Kivitelezhetőség mátrixban helyeztem el. A továbbvitt fő irány továbbra is a bejelentkezés alapú pontrendszer, mivel könnyen fejleszthető, de nagy hatással van az élő adatok hiányára. A döntéseket és a mátrix elemeit külön táblázatban bontottam szét kutatási bizonyítékokra és feltevésekre.
