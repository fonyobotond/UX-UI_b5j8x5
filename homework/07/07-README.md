## Mit készítettem a héten
A fő feladat a héten a drótvázból egy interaktív, kattintható prototípust létrehozni a projekhez. Emellett elvégeztem egy tesztelést egy barátommal, amelyhez összeállítottam egy részletes dokumentációt. 

### Megoldás összefoglalása
A prototípusban összekötöttem a fő felhasználói utat, amelyen keresztül a tesztelő sikeresen becsekkolhat egy kiválasztott meccsre (kizárólag az 'Irányító' pozíciót használva). Kidolgoztam egy hibaágat is a hiányzó űrlapadatok esetére. A feladatot egy jegyzetek oldallal tettem teljessé, ahol a tesztnek a dokumentációja látható.
